# List of Projects

This page lists the community projects hosted in the xarray-contrib organization. Projects are organized by category.

## Geospatial

| Project | Description |
|---------|-------------|
| [xarray-spatial](https://github.com/xarray-contrib/xarray-spatial) | Spatial analysis algorithms for xarray implemented in numba |
| [xdggs](https://github.com/xarray-contrib/xdggs) | Xarray extension for Discrete Global Grid Systems (DGGS) |
| [xvec](https://github.com/xarray-contrib/xvec) | Vector data cubes for Xarray |
| [xarray-regrid](https://github.com/xarray-contrib/xarray-regrid) | Regridding utility for xarray |
| [rasterix](https://github.com/xarray-contrib/rasterix) | Raster tools for xarray |
| [xproj](https://github.com/xarray-contrib/xproj) | Xarray extension for managing geospatial coordinate reference systems |

## Data Analysis & Statistics

| Project | Description |
|---------|-------------|
| [xskillscore](https://github.com/xarray-contrib/xskillscore) | Metrics for verifying forecasts |
| [flox](https://github.com/xarray-contrib/flox) | Fast & furious GroupBy operations for dask.array |
| [xeofs](https://github.com/xarray-contrib/xeofs) | Comprehensive EOF analysis in Python with xarray |

## Data I/O & Conventions

| Project | Description |
|---------|-------------|
| [cf-xarray](https://github.com/xarray-contrib/cf-xarray) | An accessor for xarray objects that interprets CF attributes |
| [xncml](https://github.com/xarray-contrib/xncml) | Tools for manipulating NcML (NetCDF Markup Language) files with xarray |
| [cf-codecs](https://github.com/xarray-contrib/cf-codecs) | Encoding and decoding of data using CF conventions |

## Machine Learning

| Project | Description |
|---------|-------------|
| [xbatcher](https://github.com/xarray-contrib/xbatcher) | Batch generation from xarray datasets |

## Visualization

| Project | Description |
|---------|-------------|
| [xarray_leaflet](https://github.com/xarray-contrib/xarray_leaflet) | An xarray extension for tiled map plotting |

## Array Backends & Units

| Project | Description |
|---------|-------------|
| [pint-xarray](https://github.com/xarray-contrib/pint-xarray) | Interface for using pint with xarray, providing convenience accessors |
| [cupy-xarray](https://github.com/xarray-contrib/cupy-xarray) | Interface for using CuPy in xarray, providing convenience accessors |

## Domain-Specific

| Project | Description |
|---------|-------------|
| [xarray-simlab](https://github.com/xarray-contrib/xarray-simlab) | Xarray extension and framework for computer model simulations |
| [xwrf](https://github.com/xarray-contrib/xwrf) | A lightweight interface for working with Weather Research and Forecasting (WRF) model output in Xarray |

## Indexing & Selection

| Project | Description |
|---------|-------------|
| [xoak](https://github.com/xarray-contrib/xoak) | Xarray extension that provides tree-based indexes for selecting irregular, n-dimensional data |
| [xarray-indexes](https://github.com/xarray-contrib/xarray-indexes) | A gallery of custom Xarray indexes |

## Schema & Validation

| Project | Description |
|---------|-------------|
| [xarray-schema](https://github.com/xarray-contrib/xarray-schema) | Schema validation for Xarray objects |
| [xarray-dataclass](https://github.com/xarray-contrib/xarray-dataclass) | Xarray data creation by data classes |

# Volunteer to Maintain a Project

To volunteer to help maintain a project in the `xarray-contrib` organization, please [request access](https://github.com/xarray-contrib/xarray-contrib/issues/new?template=help-maintain.yaml).

## Who Can Volunteer?

We welcome volunteers at all experience levels. When you submit your request, you'll indicate your experience level:

- **Total beginner but enthusiastic** - You're more than welcome! We'll help you learn the Xarray ecosystem.
- **Looking for good reviews with tips** - You have some experience and would appreciate guidance.
- **Experienced developer with Xarray ecosystem** - You're comfortable maintaining projects independently.

## What Can You Help With?

- Address reported issues and feature requests
- Update an archived repository to make it work on the latest Xarray version
- Improve an extension with new features or documentation

## Process

1. Submit a [volunteer request](https://github.com/xarray-contrib/xarray-contrib/issues/new?template=help-maintain.yaml) indicating which project you'd like to help with
2. An xarray-contrib maintainer will review your request
3. Once approved, you'll be granted appropriate permissions to the repository
